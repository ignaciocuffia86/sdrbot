# sdrbot

SDR BOT de Biguá sobre Grok Bot: prospección por señales y derivación de interesados a clientes finales, operado de forma centralizada para varios clientes.

Estado: piloto con BairesQA. La documentación está en [`docs/`](docs/README.md); lo que sigue después del piloto, en [`docs/08-roadmap-proveedores.md`](docs/08-roadmap-proveedores.md).

- [`gateway/`](gateway/README.md): gateway de correo (IMAP/SMTP, panel `/admin` y chequeo de dominios), desplegado en `https://sdrbot.bigua.lat`. Microsoft 365 y Google Workspace, en el roadmap.
